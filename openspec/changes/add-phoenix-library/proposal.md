# Change: Add PHOENIX Library

## Why
The project aims to create PHOENIX, a Python library for reactive chemical hazard evaluation as a successor to ASTM CHETAH. This library will provide thermodynamic estimation, hazard classification, and safety screening for chemical compounds.

## What Changes
- Add core PHOENIX library with thermodynamic calculations
- Implement Benson group additivity methods
- Add linear programming for decomposition analysis
- Include hazard classification algorithms
- Create Python API for molecule analysis

## Impact
- Affected specs: phoenix (new capability)
- Affected code: New phoenix/ directory with core modules
